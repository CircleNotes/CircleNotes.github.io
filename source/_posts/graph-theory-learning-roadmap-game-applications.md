图论学习的目标，是面对一个新的游戏需求，能够识别其中的关系、建立合适的图模型，解释算法为什么成立，并把它实现成可验证、成本可控的程序。

这份路线面向已经了解基本容器、具备编程基础的学习者。实践采用 C#，先在独立的小程序中验证，再把算法接入游戏场景；Unity 可以作为可视化和运行时实验的载体。

全文沿着三条线推进：**历史上问题怎样出现，数学上方法怎样成立，工程上方法怎样使用。** 下方的复选框都是待完成的学习任务，发布这份路线不代表已经完成学习。

## 一、学习目标与推进方式

最终希望具备五项能力：

1. **建模：** 说明顶点、边、方向、权重和状态分别代表什么，以及模型忽略了什么。
2. **推理：** 从定义出发推导性质，理解关键证明，能够主动构造反例。
3. **选择：** 根据问题目标、图的结构和规模选择算法，明确适用条件。
4. **实现：** 编写可解释、可验证的 C# 实现，分析时间和空间成本。
5. **落地：** 处理游戏中的动态变化、每帧预算、状态一致性和实际行为。

每次学习按下面的流程展开：

> 具体问题 → 自己提出解法 → 小图推演与反例 → 提炼概念 → 推导算法 → 证明与复杂度 → 游戏实验 → 复盘。

这里采用以提问和对话推进的学习方式：先尝试解释现象，再引入必要的定义和方法。遇到证明时，把关键推理写完整；遇到算法时，说明每一步依赖什么条件。

例如，路径搜索可以沿着这组问题推进：

- 通道代价相同，为什么按层探索可以找到边数最少的路线？
- 加入不同地形成本后，为什么第一次发现一个位置不再保证代价最小？
- 怎样调整探索顺序，才能安全地确定最短距离？
- 已经知道目标方向，能否少探索一些区域？
- 用估计指导搜索时，什么条件能避免丢失最优解？

这组问题分别引向 BFS、松弛、Dijkstra 和 A*。它们是教学上的递进关系，不能直接当作历史上的发明顺序。

## 二、历史主线：图论为何诞生，又怎样发展

图论从不同问题中逐渐形成多个交织的分支。学习历史时，关注当时的问题、抽象方式和新增能力；涉及年代时，区分提出、发表和后续完善。

| 历史节点 | 推动研究的问题 | 带来的思想与本路线的连接 |
|---|---|---|
| 1736 年前后，欧拉研究七桥问题 | 能否一次行走，每座桥恰好经过一次？ | 忽略与问题无关的形状和距离，研究连接与奇偶性；进入阶段 00、01 |
| 1847 年，Kirchhoff 研究电路网络 | 怎样分析相互连接的电路？ | 生成树与网络结构成为分析工具；联系阶段 03、07、08 |
| 1852 年，四色问题提出 | 地图相邻区域颜色不同，四种颜色是否总够用？ | 相邻关系转化为冲突约束，连接平面图与着色；进入阶段 10 |
| 1856 年前后，Kirkman、Hamilton 研究多面体上的环游 | 能否恰好访问每个顶点一次并返回？ | 对比“每条边一次”和“每个顶点一次”，理解相似描述下的不同问题；联系阶段 10 |
| 1857 年起，Cayley 研究树；1878 年 Sylvester 使用 graph 一词 | 树状结构有哪些形式？关系结构怎样描述？ | 结构、计数与化学等应用推动图论语言发展；联系阶段 03 |
| 20 世纪 50 年代，网络优化发展 | 怎样求最短路线、最低连接成本和最大运输量？ | 图成为可计算的优化模型；联系阶段 04、07、09 |
| 1968 年，Hart、Nilsson、Raphael 发表 A* 研究 | 怎样把领域知识纳入寻找最小代价路径的过程？ | 将估计用于搜索，并研究最优性条件；进入阶段 05 |
| 20 世纪 70 年代，复杂性研究与计算机辅助证明发展 | 哪些问题难以高效计算？计算机如何参与证明？ | 联系 NP 完全性，以及 1976 年四色定理证明；进入阶段 10 |

早期年代与事件可参考 [AMS 的图论历史年表](https://www.ams.org/books/spec/108/spec108-endmatter.pdf)。七桥问题通常作为图论的起点；采用现代顶点与边的语言讲解欧拉的思想，是今天的重述，不能假定当时已经存在完整的现代术语体系，参见 [欧拉七桥问题研究资料](https://old.maa.org/press/periodicals/convergence/leonard-eulers-solution-to-the-konigsberg-bridge-problem)。

网络优化部分会结合原始问题阅读：[Ford–Fulkerson 的 1956 年论文](https://doi.org/10.4153/CJM-1956-045-5)从带容量的铁路网络出发；Dijkstra 的最短路算法在 1956 年用于计算机展示，论文发表于 1959 年，见 [CWI 的历史介绍](https://www.cwi.nl/nl/over/geschiedenis/e-w-dijkstra-briljant-kleurrijk-en-uitgesproken/)。A* 则可阅读 [1968 年原论文](https://people.stfx.ca/jdelamer/courses/csci-564/_downloads/b2220c66675ddde471ca1795147b8e86/A_Formal_Basis_for_the_Heuristic_Determination_of_Minimum_Cost_Paths.pdf)，理解作者试图连接数学路径算法与启发式方法的动机。

## 三、阶段总览与依赖

主线按 00 → 11 推进。数学归纳法、反证法、循环不变量和复杂度随问题补充；容器的基本使用直接跳过。

| 阶段 | 核心问题 | 主要产物 |
|---|---|---|
| 00 历史起点 | 能否不枚举所有路线，就证明不可能？ | 七桥问题重述与证明 |
| 01 图与状态建模 | 为了回答问题，最少需要保留什么？ | 三类图模型及表示比较 |
| 02 遍历与可达性 | 怎样探索全部可能，又不反复兜圈？ | BFS、DFS 与可达性实验 |
| 03 树与结构 | 唯一路径意味着什么？ | 树的性质证明与迷宫生成 |
| 04 加权最短路 | 路线代价不同时，按层探索哪里失效？ | Dijkstra 与负权反例 |
| 05 启发式搜索 | 怎样利用目标信息减少探索？ | A* 对照实验 |
| 06 依赖与有向结构 | 有前置条件时怎样排序、定位循环？ | DAG、拓扑排序与 SCC 工具 |
| 07 最小生成树 | 怎样以最低总成本连接整个网络？ | 地牢与道路连接实验 |
| 08 连通性的脆弱处 | 哪个点或边失效会切断网络？ | 桥、割点与瓶颈分析 |
| 09 匹配与网络流 | 多个单位怎样共同分配有限资源？ | 分配与容量模型 |
| 10 约束与计算边界 | 为什么某些相似问题突然很难？ | 着色、环游与复杂性比较 |
| 11 游戏运行时整合 | 正确算法怎样变成稳定的游戏功能？ | 综合 Demo 与测量报告 |

阶段 07 使用阶段 03 的树和证明基础；阶段 08 使用阶段 02 的 DFS，并与阶段 06 的强连通性对照；阶段 09 使用前面的搜索和建模能力。第一次学习遵循主线，完成基础后可按项目需求回看分支。

## 四、详细学习任务

### 阶段 00：从七桥问题理解图论的诞生

**起始问题：** 为什么尝试了许多路线仍然失败？怎样证明所有尝试都会失败？

- [ ] **00.01 还原问题与抽象。** 阅读七桥问题资料，分别画出地理示意与连接示意；写明哪些信息被保留，为什么桥的长度不影响“每桥一次”的判断。
- [ ] **00.02 推导奇偶限制。** 从“进入一个地区后还要离开”出发，区分起点、终点和中途地区，写出奇度顶点的必要条件，并解释七桥问题为何无解。
- [ ] **00.03 区分证明不存在与构造解。** 对所有非孤立顶点连通的有限无向图，整理欧拉迹与欧拉回路的条件；用小图验证必要性与充分性的区别。完整构造算法可在遍历阶段后回访。

**产物与验收：** 一份问题、抽象、论证、适用条件齐全的短笔记；能够解释“没有找到”为什么不同于“证明不存在”。

### 阶段 01：从游戏问题建立图模型

**起始问题：** 玩家能否到达宝箱？房间位置是否足够表达这个问题？

- [ ] **01.01 建立三个关系模型。** 分别为地牢通行、传送网络和技能前置建图，说明顶点、边、方向、权重以及边存在的条件。
- [ ] **01.02 区分空间与状态。** 给地牢加入钥匙和门，比较“房间”与“房间＋钥匙集合”两种顶点定义，构造仅按房间去重会出错的例子。
- [ ] **01.03 比较图的表示。** 用同一组数据实现邻接表与邻接矩阵，比较枚举邻居、查询边、增删关系与空间成本；认识平行边、自环和隐式生成邻居。

**产物与验收：** 三张模型卡和一份表示比较；能够说明同一个场景为什么可能需要不同的图。

### 阶段 02：遍历、可达性与系统搜索

**起始问题：** 有环和岔路时，怎样确保不漏探索，并且能够结束？

- [ ] **02.01 推导 BFS。** 手工记录每轮搜索前沿、距离和父节点，再实现路径还原；解释为什么等边权条件下，按层推进得到最少边数。
- [ ] **02.02 推导 DFS。** 追踪递归或显式栈的进入、退出过程，实现可达性和无向图连通分量；说明访问标记何时设置，以及不设置的后果。
- [ ] **02.03 验证正确性与成本。** 用空图、单点、环、不连通图、平行边等样例检查；在邻接表模型下推导 O(V+E)，并比较不同表示的成本。

**产物与验收：** 可达性与迷雾探索实验；给定一张小图，能手工解释探索顺序及每个节点被处理的原因。

### 阶段 03：树、生成树与唯一通路

**起始问题：** 地牢只有唯一通路，背后是什么结构？连接所有房间至少需要多少边？

- [ ] **03.01 建立基本性质。** 推导握手定理；证明有限简单无向图中“连通且无环”“任意两点间存在唯一简单路径”等树的等价描述，解释 n 个顶点的树为何有 n−1 条边。
- [ ] **03.02 从遍历得到生成树。** 对连通图保留搜索树边，区分原图、搜索树与生成树；说明为什么一般图的路径信息不能全由一棵树替代。
- [ ] **03.03 生成并改造迷宫。** 使用随机 DFS 等方法生成树状迷宫，再加入少量非树边形成回路；比较死路、绕行与路线选择。

**产物与验收：** 可重复生成的迷宫及树性质证明；明确这种生成方式不保证从所有生成树中均匀采样。

### 阶段 04：加权最短路与贪心的依据

**起始问题：** 沼泽只隔一个格子，为什么可能应该绕路？

- [ ] **04.01 找到 BFS 的边界。** 构造“边数更少但总代价更高”的小图，定义距离估计、松弛和父节点更新；区分首次发现与最短距离确定。
- [ ] **04.02 推导 Dijkstra。** 说明为何选择当前距离最小的候选，证明非负边权下确定距离的安全性；实现过期队列项处理、不可达情况和路径还原。
- [ ] **04.03 用反例理解限制。** 构造负权边破坏直接定点结论的例子，学习 Bellman–Ford 的重复松弛及可达负环检测；多源与全源最短路作为后续扩展。

**产物与验收：** 带地形成本的寻路程序；能解释为什么算法成立，负权环在什么情况下使所求的最短距离没有有限值。

### 阶段 05：A* 与有依据的估计

**起始问题：** 怎样利用目标位置减少探索，同时控制估计造成的错误？

- [ ] **05.01 比较三种选择标准。** 在同一地图手推只看已付代价、只看目标估计、两者相加的搜索，认识 g、h 和 f=g+h 的作用。
- [ ] **05.02 推导启发函数条件。** 学习可采纳性和一致性，按移动规则与最小步行成本构造距离下界；检查斜走、传送和低成本边是否破坏原估计。
- [ ] **05.03 实现与测量 A\*。** 与 Dijkstra 比较路径代价、展开节点数、耗时和内存；采用一致启发式安全关闭节点，或在允许不一致的可采纳启发式时正确处理更优路径与重新展开。

**产物与验收：** 对照地图和实验记录；能说明 h=0 时与 Dijkstra 的关系，以及“找到目标”与“可以正确结束”的区别。

### 阶段 06：有向依赖、循环与调度

**起始问题：** 任务 A 等 B，B 又等 A，如何发现和解释这种阻塞？

- [ ] **06.01 从先后关系得到 DAG。** 明确前置任务指向后续任务的边语义，用小图说明有向环怎样造成循环依赖；区分图的连通与可达方向。
- [ ] **06.02 推导拓扑排序。** 从入度为零的任务出发实现排序；剩余节点未处理时判断存在环，但不能把全部剩余节点都直接标成环内节点。
- [ ] **06.03 定位循环与计算依赖。** 学习强连通分量并定位循环依赖组；把分量收缩成 DAG，在 DAG 上计算前置条件满足后的最早完成时间，明确资源无限或已另行处理的假设。

**产物与验收：** 任务或科技依赖检查器；能区分“处于环内”和“受环阻塞”，并解释排序为何可能不唯一。

### 阶段 07：最小生成树与整体连接成本

**起始问题：** 让各个房间到入口的路径最短，为什么不等于走廊总建设成本最低？

- [ ] **07.01 区分两个优化目标。** 在小图上比较最短路径树与最小生成树；明确连接所有顶点、边权总和最小的目标及无向图前提。
- [ ] **07.02 推导安全选边。** 学习割性质、环性质和交换论证，理解并查集怎样维护连通分量；实现 Kruskal，并手推 Prim 作为对照。
- [ ] **07.03 应用于房间连接。** 以房间和候选通道建图生成连接网络，再加入备用边；记录权重相等、不连通输入和不可施工边的处理。

**产物与验收：** 地牢或道路连接实验；能够解释 MST 只保证给定候选图与成本模型下的最优，不自动保证游戏体验或几何通道可施工。

### 阶段 08：桥、割点与结构脆弱性

**起始问题：** 哪条通道被封锁，会把地图分成互不相通的区域？

- [ ] **08.01 先做可解释的基线。** 枚举删除一条边或一个点，重新计算连通分量；写出桥与割点的定义，并说明它们与几何交叉无关。
- [ ] **08.02 推导 DFS 判据。** 从子树能否通过其他边回到祖先出发，学习发现时间和 low-link；处理 DFS 根节点特例，并以边 ID 正确区分平行边。
- [ ] **08.03 验证瓶颈判断。** 用暴力删除基线核对高效结果，在地牢里标出关键通道和房间，再增加备用连接观察结构变化。

**产物与验收：** 瓶颈可视化与小图核对记录；区分“断开整体连接”“加大绕路成本”和“降低运输容量”。

### 阶段 09：匹配、增广与容量网络

**起始问题：** 每个 NPC 都优先选最近岗位，为什么可能导致别人无岗可去？

- [ ] **09.01 建立分配模型。** 认识二分图与奇环判定；区分最大匹配、极大匹配、完美匹配和最小成本分配；用小图理解 Hall 定理的条件。
- [ ] **09.02 推导增广路。** 从撤销局部安排并重新分配出发，实现二分图最大匹配；与小规模穷举结果对照，解释为什么一次局部最近选择不足以优化整体。
- [ ] **09.03 进入网络流。** 从运输容量建立源点、汇点、容量与流量守恒，学习残量网络和反向边；实现一种基础最大流算法，理解最大流最小割。带成本分配另设扩展实验。

**产物与验收：** 岗位分配与运输容量小实验；能够说明最大匹配、最大流分别优化什么，不能把它们直接称为“总距离最短”。

### 阶段 10：着色、环游与计算难度

**起始问题：** 每条边一次和每个顶点一次，仅改变了对象，为什么问题性质就可能完全不同？

- [ ] **10.01 研究冲突与着色。** 建立任务冲突图，实现贪心着色并比较不同处理顺序；学习平面图、连通平面嵌入下的 V−E+F=2，以及四色定理的适用范围。
- [ ] **10.02 比较两类环游。** 对照欧拉迹与哈密顿路径或回路，在小图上穷举；联系巡逻覆盖道路、访问全部据点和旅行商问题，分别写清约束与目标。
- [ ] **10.03 理解复杂性与工程取舍。** 学习多项式时间、验证与求解的区别、问题归约和 NP 完全性的基本含义；为一个小实例比较精确搜索与限时启发式结果。

**产物与验收：** 问题比较表与反例；不把“当前没有已知多项式算法”说成已经证明绝无高效算法，也不把一般冲突图套用四色保证。

### 阶段 11：从算法到游戏运行时

**起始问题：** 小程序正确，为什么接入游戏后仍会卡顿、走错路或使用过期结果？

- [ ] **11.01 处理变化与状态。** 为开关门、通道破坏和钥匙变化设计图更新与版本记录；检测搜索期间图变化，并在结果失效时重新请求或丢弃。
- [ ] **11.02 测量并限制计算成本。** 建立同步搜索基线，记录规模、耗时分布、展开节点数和分配量；尝试按展开节点数分帧、取消请求、共享距离场，并说明对应的适用场景。
- [ ] **11.03 整合游戏行为。** 在游戏场景中演示路径跟随、动态阻塞和多单位请求；明确全局路径规划、运动控制、局部避障的职责，在目标设备上检查行为与帧时间。

**产物与验收：** 可复现的综合 Demo、输入参数与运行报告；源代码检查和独立程序验证分别记录，游戏运行与设备测量需要实际执行后才能标记通过。

## 五、三个持续扩展的实践作品

这些作品复用阶段任务的成果，不另开三套重复工程。

| 作品 | 逐步加入的能力 | 核心验收 |
|---|---|---|
| 地牢分析与生成器 | 可达性 → 树状迷宫 → MST 连接 → 备用通道 → 桥与割点 | 固定种子可复现；能解释连通、回路和瓶颈的变化 |
| 路径搜索实验场 | BFS → 地形权重 → Dijkstra → A* → 钥匙状态 → 动态变化 | 同一成本模型下对照最优代价；记录探索成本和失效条件 |
| 依赖与分配工具 | DAG → 拓扑排序 → SCC → 岗位匹配 → 容量网络 | 能定位循环；分配满足约束；清楚说明优化目标 |

可用四个里程碑检查整体进度：

- **完成 00—03：** 能从问题建立图模型，完成基本证明与遍历，解释树状地牢的性质。
- **完成 04—05：** 能推导并验证加权与启发式路径搜索，说明最优性条件。
- **完成 06—10：** 能处理依赖、整体连接、脆弱性、分配与冲突，判断计算边界。
- **完成 11：** 能把模型和算法放入实际游戏，解释行为、成本与限制。

## 六、扩展方向与参考资料

第一轮先完成主线。出现明确问题后，再选择扩展：

- 大量单位前往同一目标：反向最短路、多源搜索、距离场与流场。
- 地图很大或频繁变化：分层寻路、增量搜索、动态图；明确抽象可能损失什么。
- 随机关卡研究：随机图、生成分布、连通性与结构统计。
- 关卡解谜：乘积状态空间、状态压缩、约束搜索与状态爆炸。
- 更多理论：平面图、极值图论、谱图论与概率方法。
- 更复杂的分配：最小费用流、带权匹配，以及时间和空间冲突约束。
